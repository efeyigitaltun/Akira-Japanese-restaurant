AKIRA - Japon Restoranı

Proje Hakkında:
Japon mutfağının zarafetini ve sadeliğini dijital dünyaya yansıtmak amacıyla tasarlanmış modern bir web projesidir. 
Proje; özgün marka kimliği, dikkatle seçilmiş tipografi (özel Türkçe karakter destekli *The Seasons* font entegrasyonu) ve kullanıcı dostu arayüz tasarımı ile ön plana çıkmaktadır.

 Özellikler

- Göz Alıcı ve Minimalist Tasarım:Japon estetiğine ve restoran konseptine uygun sıcak/doğal renk paleti.
- Duyarlı Tasarım (Responsive Layout): Mobil, tablet ve masaüstü cihazlarda kusursuz görünüm.
- Menü Sergileme: Sushi, Ramen ve geleneksel lezzetlerin görsel odaklı, modern bir düzende sunumu.
- Özel Markalama:Şeffaf arkaplanlı logo entegrasyonu ve estetik odaklı CSS font optimizasyonları.
- Lighthouse Skorları: Lighthouse skorlarında 4 farklı kategoride 95+ skorlar elde ettik. 

Kullanılan Teknolojiler

- HTML5 – Semantik ve güçlü sayfa iskeleti
- CSS3 – Flexbox/Grid mimarisi, modern arayüz geliştirmeleri ve özel font yapılandırmaları
- JavaScript – Dinamik etkileşimler
- Git & GitHub – Versiyon kontrolü ve ekip işbirliği
- Canva – Logo optimizasyonu ve grafik tasarımları
  
Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak ve kodları incelemek için aşağıdaki adımları takip edebilirsiniz:

1. Projeyi Klonlayın:
   ```bash
   git clone [https://github.com/efeyigitaltun/Akira-Japanese-restaurant.git](https://github.com/efeyigitaltun/Akira-Japanese-restaurant.git)
2.Proje Klasörüne Gidin:

    cd Akira-Japanese-restaurant
      
3.Çalıştırın:
Herhangi bir sunucu kurulumuna gerek duymadan, ana dizindeki index.html dosyasını favori tarayıcınızda açarak projeyi görüntüleyebilirsiniz.
(Geliştirme sürecinde Canlı Önizleme için VS Code "Live Server" eklentisi önerilir.)
